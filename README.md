# Calculator DevOps

A Calculator REST API built with Java and Spring Boot, supported by automated
testing and a CI/CD pipeline using GitHub, Jenkins, Docker and Docker Compose.

## Project Status

Currently under development.

## Planned Features

- REST endpoints for addition, subtraction, multiplication and division
- Structured error handling and input validation
- JUnit 5 unit tests and Spring MVC integration tests
- Multi-stage Docker image
- Docker Compose deployment with Nginx
- Jenkins CI/CD pipeline with automated testing and deployment
